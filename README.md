# Free Tinnitus Help — iPhone

Private native iOS source repository for Free Tinnitus Help.

Current handoff baseline: iPhone Native v1.8 device-test candidate.

Core requirements:
- Native iPhone app
- Offline core operation
- Background audio must continue while the iPhone screen is locked
- Personalized multi-layer tinnitus sound matching
- Local saved profiles and timer
- No subscription/paywall

The authentic `dt.sound` recording is intentionally not substituted when absent.
